# MentorWise AI Platform 🚀

> An AI-powered career accelerator and mentorship ecosystem empowering university students and freshers with autonomous mock interviews, internship discovery, and AI career agents.

## 🌟 Key Features

- **🎙️ Live AI Mock Interview Simulator:** Voice and text interview practice evaluating responses against the **STAR framework** (Situation, Task, Action, Result) with real-time behavioral telemetry.
- **🤖 Autonomous Career Agents:** Multi-agent network offering tailored mentorship across software engineering, product management, resume optimization, and executive presence.
- **💼 Curated Internship Board:** Verified fresher and student internship listings with skill-matching algorithms.
- **⚡ Community & Events:** Live workshops, founder masterclasses, and an active student career feed.
- **🔍 SEO & Discoverability:** Built with structured JSON-LD schemas, automated sitemaps, and optimized metadata for high search rankings.

---

## 🛠️ Tech Stack

- **Frontend Framework:** [TanStack Start](https://tanstack.com/start) / React 18 / TypeScript
- **Styling & UI:** Tailwind CSS, [shadcn/ui](https://ui.shadcn.com/), Lucide Icons
- **Backend & Database:** [Lovable Cloud](https://docs.lovable.dev/features/cloud) / Supabase (PostgreSQL, Edge Functions, Auth)
- **AI Engine:** Google Gemini & Lovable AI Gateway
- **Deployment:** Lovable Edge Network
